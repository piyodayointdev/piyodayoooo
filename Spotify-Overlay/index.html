Features

Dynamic Color

再生中のアートワークのピクセル平均から、その曲に最適なカラーを自動計算。アプリ全体の透明度やバックグラウンド発光へ直感的に同期します。

3D Rolling Lyrics

C++層での座標計算アルゴリズムに基づき、円筒投影されたかのように曲面を流れる立体的な歌詞表現を搭載。滑らかな進入・退出処理を処理します。

Rolling Time

システム時間や曲の経過秒数を、1桁ごとに上下へフリップローリングさせて描画。細部までDirect2Dの超軽量・高フレームレート処理が活きています。
